# AstroStarCheck

Free astrology charts computed with Swiss Ephemeris.

Website: https://astrostarcheck.com

## What it does

- Natal charts, Firdaria periods, solar returns, synastry and transits
- Swiss Ephemeris precision
- Chart computation runs in the browser, so birth data stays on your device
- 11 languages
- A public JSON chart endpoint

## Why it exists

People need a chart calculator that loads fast, answers in their own language, and does not require an account. AstroStarCheck does that and nothing else.

## Note

Astrology is a symbolic interpretive tradition, not a scientifically validated predictor. Use the charts as a reflective tool.
